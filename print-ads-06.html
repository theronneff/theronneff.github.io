Private Jet Ads

the ask

Set Jet, based in Scottsdale, is a membership-based private jet charter program that provides luxurious jet travel at an affordable price. Set Jet wanted full-page print ads for ICONIC LIFE Luxury Magazine, Orange County Magazine, and Jetset Magazine. The goal was to drive new membership signup.

the answer

Staying true to Set Jet’s brand standards, I created full-page 4-color print ads representing the essence of the Set Jet brand. The creative conveyed a luxurious private jet experience at an affordable cost. These full-page print ads helped drive awareness, new memberships, and revenue.
